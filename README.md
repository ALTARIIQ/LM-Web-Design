## Legendary Motorsport Showcase Web Design

A dynamic web built as part of the *Introduction to Web Programming* course at Nişantaşı University. The project is inspired by the iconic "Legendary Motorsport" interface, offering a sleek platform to browse, showcase, and interact with high-end luxury vehicles.

---
## Features

- Interactive Car Showcase: Dynamically loaded vehicle catalog powered by JavaScript (`data.js`).
- User Authentication UI: Dedicated Login interface with custom client-side scripts.
- Custom Styling & UI/UX: Built-in modular CSS stylesheets (`navbar.css`, `cars.css`, `login.css`, `style.css`).
- Media Integration: Integrated video showcase and responsive vehicle branding assets.
- Responsive Navigation: Clean navigation bar for seamless user browsing.

---

##  Tech Stack

- Frontend: HTML5, CSS3 (Modular Stylesheets)
- Logic & Dynamics: Vanilla JavaScript (ES6)
- Design Inspiration: Grand Theft Auto V (Legendary Motorsport Theme)
